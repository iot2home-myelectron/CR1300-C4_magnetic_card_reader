CR1300-C4 เครื่องอ่านการ์ดแถบแม่เหล็ก (Magnetic Stripe Card Reader) 
***********************************************************
ประสิทธิภาพสูงที่เชื่อมต่อผ่านพอร์ตอนุกรม (Serial / RS232 Interface) ออกแบบโครงสร้างมาให้มีขนาดกะทัดรัด (Mini size)  เหมาะสำหรับวิศวกรและนักพัฒนาที่ต้องการนำไปอินเตอร์เฟสร่วมกับกล่อง GPS Tracker (ระบบติดตามรถขนส่งและรถโดยสาร), ระบบควบคุมการเข้า-ออกประตู (Access Control), เครื่องรูดบัตร หรือระบบตู้คีออส

คุณสมบัติทางเทคนิค (Technical Specifications)
 Dimension: ขนาดกะทัดรัดเป็นพิเศษเพียง \bm{90\text{mm(L)} \times 30\text{mm(W)} \times 26\text{mm(H)}}
 Weight: น้ำหนักเบา ประมาณ \bm{85\text{g}}
 Power Supply: \bm{+5\text{V DC} \pm5\%} | Power Consumption: ต่ำกว่า \bm{40\text{mA (max.)}}
 Card Standard: รองรับมาตรฐานสากล ISO7811 / 7812
 Track Position: รองรับการอ่านตำแหน่งแทร็กแบบครอบคลุม:
 ISO 1 (IATA): 210 BPI (79 Characters, 7bits)
 ISO 2 (ABA): 75 BPI (40 Characters, 5bits) – รองรับแถบแม่เหล็กบนใบขับขี่และบัตรมาตรฐานทั่วไป
 ISO 3 (MINTS): 210 BPI (107 Characters, 5bits)
 Interface: Serial (RS-232 มาตรฐานหัวพิน DB9 Female)
 Interface Definition: 1 (Red) - 5V(VCC) | 2 (Green) - TXD | 3 (Yellow) - RXD | 5 (Black) - GND
 Life of Head: อายุการใช้งานหัวอ่านสูงถึง 500,000 ครั้ง (Card passes)
 Error Rate: อัตราความผิดพลาดต่ำมาก น้อยกว่า 0.5% (JSE Test card)

⚡ จุดเด่นและการประยุกต์ใช้งาน (Applications)
 GPS Tracker Integration: สามารถต่อเข้ากับพอร์ต RS232 ของกล่อง GPS ในรถบรรทุก รถวัตถุอันตราย หรือรถโดยสาร เพื่ออ่านข้อมูลแถบแม่เหล็กหลังใบขับขี่สำหรับยืนยันตัวตนคนขับตามกฎหมายกรมการขนส่งทางบก
 Access Control & Security: ใช้ต่อพ่วงกับบอร์ดไมโครคอนโทรลเลอร์หรือชุดควบคุมประตู เพื่ออ่านบัตรผ่านเข้า-ออกอาคาร
 Industrial Grade: ทนต่ออุณหภูมิใช้งานได้กว้างตั้งแต่ \bm{-20^\circ\text{C}} ถึง \bm{+70^\circ\text{C}} เหมาะสำหรับงานติดตั้งภายในรถยนต์และในอาคาร
